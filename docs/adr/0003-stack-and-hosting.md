# ADR 0003: 기술 스택과 배포 위치

- 상태: 채택 (2026-11-24, 사용자 확정)

## 결정
- 엔진·서버: .NET 10, C#, ASP.NET Core, SignalR
- 화면: React + Vite (TradingView Lightweight Charts 등 무료 차트 라이브러리 검토)
- 테스트: xUnit, FsCheck(속성 기반 테스트)
- 배포: 기존 Oracle 무료 VM(골목장부와 같은 서버)에 함께 올린다

## 이유
- React는 골목장부에서 써 봐서 화면 개발 속도가 빠르고, 금융 차트 라이브러리 선택지가 많다.
- 추가 비용 없이 공개 주소로 시연할 수 있다.

## 단점과 대응
- 화면은 C#이 아니다. 발표에서는 "엔진과 서버가 C#"이라고 정확히 말한다.
- 같은 VM이라 자원 경쟁이 있다. 부하 측정은 로컬에서 하고, VM에서는 시연 규모(봇 수십 개)만 돌린다. 배포 전에 VM 메모리 여유를 확인한다.
