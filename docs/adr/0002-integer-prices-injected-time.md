# ADR 0002: 정수 가격과 주입 시각

- 상태: 채택 (2026-11-24)

## 결정
- 가격(원)과 수량(주)은 `long`. 엔진에서 `double`, `float`, `decimal`을 쓰지 않는다.
- 비율 계산(가격제한폭 30%, VI 3%/6%/10%)은 정수 연산으로 한다. 예: `base * 3 / 10`은 정수 나눗셈 후 호가단위 절사.
- 비율 비교는 나눗셈 대신 곱셈으로 한다. 예: `|p - ref| * 100 > ref * rate`.
- 시각은 `long` 논리 ms. 실제 시각과의 연결과 시연용 배속은 서버 계층이 맡는다.

## 이유
- 부동소수 오차로 상하한가가 1원 어긋나면 규정 테스트가 깨진다.
- 시각을 주입하면 2분 단일가와 30초 랜덤 엔드를 테스트에서 즉시 재현할 수 있다.

## 단점
- 비율 비교에서 곱셈 오버플로를 조심해야 한다(가격 상한을 정해 두고 테스트).
