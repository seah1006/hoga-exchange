# REVIEW-8 화면 수정 결과

- 범위: `fix/REVIEW-8-w`, `web/`과 이 문서. 서버 구현·배포는 제외했다.
- 기준: REVIEW-8A/8B, ADR 0005의 REVIEW-8 결정, API 계약 v0.5.1 3장.

## 항목별 결과

1. **평가액·손익·수익률 실시간 갱신 (8B M4).** 최신 `bookSnapshot.lastPrice`와 계좌 객체의 주문 가능 현금·주식 및 묶인 현금·주식으로 `valuation = cash + cashOnHold + (shares + sharesOnHold) × lastPrice`를 계산한다. `pnl = valuation − initialValuation`, `returnBp = pnl × 10,000 ÷ initialValuation`(소수부를 0 방향으로 버림)은 서버 랭킹과 같다. 최신가가 없거나 유효하지 않으면 서버 값을 표시한다. 랭킹은 기존 서버 스냅샷을 계속 표시하므로 조회 시점은 다를 수 있다. 타인 체결로 9,450원에서 9,380원으로 바뀐 경우 추가 계좌 알림이나 조회 없이 갱신되는지, 양쪽 보유분과 음수 수익률 절삭 및 서버 값 대체를 검증했다.
2. **로그인·탈퇴 오류 안내.** 로그인 401은 계정 존재·잠금 여부를 구분하지 않는 한 문구로 표시한다. 로그인·탈퇴 429는 응답 본문에 관계없이 같은 재시도 안내를 표시하며, 구형 `LockedOut` 분기를 삭제했다. 탈퇴의 비밀번호 오류 안내는 유지했다. 목 로그인에는 기존 시뮬레이션 한도(5회·5분, 임의 지정)를 유지하되 `LockedOut` 대신 일반 제한 오류를 사용한다. 한도 수치는 화면에 표시하지 않는다.
3. **개인정보 안내 (8A P1-8).** 로그인 기록 30일 보관, 탈퇴 시 계정과 로그인 기록 삭제, 삭제 정보가 서버 백업에 최대 7일 남을 수 있음, 지난 랭킹의 ‘탈퇴한 사용자’ 표시를 명시했다. 화면 문구는 DOM 테스트로 확인했으며 서버의 실제 보존·삭제는 이 작업 범위에 포함하지 않았다.
4. **다계정 한계 고지.** 랭킹에 ‘교육용 모의투자 · 한 사람이 여러 계정을 쓰는 경우를 막지 않습니다.’를 표시한다. 랭킹 자격이나 순위 계산은 변경하지 않았다.
5. **로그아웃·탈퇴 직후 개인 상태 제거.** 성공 응답 뒤 CSRF 토큰 재발급이나 기존 SignalR 연결 종료를 기다리지 않고 계좌·내 주문·내 체결 화면을 내린다. 이전 허브와 새 익명 허브의 계좌 알림은 무시하고 공개 시세는 계속 받는다. 늦게 끝난 세션 조회도 로그아웃 이전 사용자를 복원하지 못한다. 토큰 갱신·허브 정지를 지연시키고 이전 알림을 늦게 보내는 테스트 및 재로그인 후 정상 수신 테스트로 확인했다.
