# REVIEW-8 수정 기록

## 서버 (`fix/REVIEW-8-s`)

| 항목 | 원인과 수정 | 검증 |
|---|---|---|
| 1. 로그인 열거 | 계정 없음과 잠금이 다른 작업·응답을 반환했다. 동일한 `401 InvalidCredentials` 본문을 쓰며, 없는 계정·잠긴 계정도 현재 Identity 작업 계수로 만든 더미 해시를 검증한다. 네트워크 전체의 절대 동일 시간은 보장하지 않는다. | `Review8LoginFailureBodiesMatchAndIndependentQuotasApply`, 기존 회원 계약 테스트 |
| 2. 로그인 제한·감사 | IP와 정규화한 이메일 해시를 각각 제한한다. IP당 30회/분, 이메일당 8회/분, 해시 검증 동시 8개 및 무대기 전역 admission(모두 임의 지정)이다. 같은 이메일의 잠금 갱신은 스트라이프에서 직렬화한다. 시작 및 백업 주기에 30일 지난 감사 행을 정리하며, 탈퇴에는 외래 키 연쇄 삭제를 적용한다. | 동일성·429 시험, WAL/감사 정리 시험 |
| 3. 가입 | ADR 결정대로 `EmailTaken`을 유지한다. 실제 중복과 다른 등록 오류를 구별한다. 기존 IP당 10회/시간 제한(임의 지정)을 유지한다. | 가입 계약과 11번째 요청 429 |
| 4. 탈퇴 | 비밀번호 확인에 사용자당 5회/5분 및 IP당 20회/5분(임의 지정)을 적용한다. | 6번째 재인증 429 |
| 5. 세션·역할 | 로그아웃은 보안 스탬프를 바꾸고 모든 기존 세션을 철회한다. 매 요청마다 스탬프와 현재 역할을 확인한다. 로그아웃·탈퇴 시 기존 허브의 비공개 구독만 제거하고 공개 시세 연결은 유지한다. | 탈퇴·로그아웃의 기존 쿠키 401 및 기존 연결의 공개 초기화 이벤트 유지/계좌 이벤트 미수신 |
| 6. 허브 Origin | Origin이 있으면 동일 출처 또는 설정된 정확한 출처만 허용한다. Origin을 보내지 않는 네이티브 클라이언트는 그대로 사용할 수 있다. | 동일·설정·비허용·null 출처 협상 |
| 7. 운영 헤더 | Production에서 HTTPS HSTS, CSP, 프레임 차단, nosniff 및 Referrer-Policy를 설정한다. 인증 API는 `no-store`다. | Production 응답 헤더 시험. 화면 실접속은 하지 않았다. |
| 8. SQLite | WAL, 100 ms SQLite busy handler 및 1초 공급자 명령 재시도 상한(임의 지정)을 적용했다. 정상 경합은 WAL로 완화한다. 라운드 저장·탈퇴는 원장 순서와 DB 커밋을 어긋나게 하지 않기 위해 시장 루프에 유지한다. 쓰기 잠금을 획득하지 못하면 503으로 실패한다. 순위 기록량과 디스크 속도에 따른 정상 커밋 시간까지 제한하는 것은 아니다. | 쓰기 잠금이 유지된 상황에서 초기화 503·헬스 200·해시 불변, 온라인 WAL 스냅샷 시험 |
| 9. 원장 재생 | 현금·주식·보유분 음수, 예약 수량 초과 체결, 재생된 열린 주문과 보유분 합 불일치를 거부한다. 일치하는 `.round`가 없다면 명시적 레거시 우회 없이는 기동하지 않는다. | 음수 및 `.round` 누락 기동 거부, 기존 재시작 테스트 |
| 10. 재해 복구 | 시장 체크포인트에서 SQLite 온라인 스냅샷과 활성 저널 길이, `.round`, 보관 저널 및 키를 확보한다. ZIP 압축은 시장 루프 밖에서 하고 완성본만 공개한다. 시작·초기화 직후·매시간 생성 요청, 7일 보관은 임의 지정이다. 다운로드와 복원은 `deploy/DEPLOY.md`에 적었다. | 일일 초기화 백업, WAL 행 보존, ZIP만 풀어 새 서버의 상태·원장 해시 및 기존 쿠키 확인 |
| 11. 단일가 부분 체결 | 단일가에서 일부 체결된 매수의 미체결분만 예약되고 이후 취소로 풀리는지 고정 시계로 검증했다. | `Review8PartialAuctionFillSettlesOnlyExecutedQuantity` |

서버 정책은 단일 앱 인스턴스 기준이다. 예상보다 SQLite 쓰기/체크포인트 시간이 늘어나는 운영 환경의 부하 측정과 공개 서버 실검증은 이번 작업 범위가 아니다.
