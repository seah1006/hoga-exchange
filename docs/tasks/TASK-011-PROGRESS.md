SignalR 계좌 갱신은 소유 연결에만 전송한다.
- `Ranking/`: 장중 순위는 루프에서 투영만 읽어 수익률 내림차순, 첫 주문 순번 오름차순으로 계산한다. 공개 응답은 상위 50과 본인 순위, 닉네임만 제공한다. 장 종료 결과는 세대별 SQLite 트랜잭션에 저장하고 현재 세대 결과는 회전 성공 전 숨긴다. 같은 날짜에 관리자 초기화가 여러 번 발생하면 날짜별 조회는 최신 종료 결과를 반환한다. 탈퇴는 열린 주문 취소, SQLite 계정 삭제, 보관 순위 닉네임 익명화를 한다.
- 새 장은 시작 자산을 초기화한다. 활성 저널 옆 세대별 메타데이터에 라운드 일자와 시작 자산을 저장해 설정이 바뀌어도 같은 라운드의 재기동 결과를 유지한다. 라이브 원장은 SQLite에 중복 저장하지 않는다.
