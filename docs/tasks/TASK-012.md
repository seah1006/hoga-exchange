# TASK-012: 회원·계좌·랭킹 화면 (web)

- 브랜치: `task/TASK-012` (기준 `dev/service`). `main`과 공개 서버는 건드리지 않는다.
- 담당: 구현 에이전트 (Codex)
- 기준 문서: `docs/api/CONTRACT.md` **v0.5 3장**, `docs/adr/0005-accounts-and-rounds.md`, `AGENTS.md`, `docs/tasks/TASK-009W-PROGRESS.md`, `TASK-008W-PROGRESS.md`
- 동시 작업: TASK-011(서버). 서버는 아직 없으니 목 구현체와 계약 픽스처로 개발하고 실제 연결은 "미검증".

## 만들 것
1. **로그인·가입**: 헤더 오른쪽 "로그인/가입" 버튼 → 모달(또는 페이지). 가입: 이메일, 비밀번호(10자 이상 안내, 표시/숨김), 닉네임. 오류 코드별 한국어 안내. 로그인 후 닉네임 메뉴(내 계좌, 로그아웃, 탈퇴). 탈퇴는 비밀번호 재확인과 경고.
2. **CSRF**: 앱 시작과 로그인 직후 `GET /api/auth/csrf`, 모든 POST/DELETE에 `X-CSRF-TOKEN`. 400 `BadCsrfToken`이면 토큰 재발급 후 1회 재시도.
3. **비로그인 모드**: 시세·호가·실험 화면은 그대로. 주문창은 "로그인하면 주문할 수 있습니다" + 로그인 버튼. 관리자 패널은 Admin 사용자에게만(관리자 키 입력란은 운영용으로 접어 둠).
4. **내 계좌 패널**: 현금(주문 가능/묶임), 주식(매도 가능/묶임), 평가액, 손익, 수익률(%) — `accountUpdate`로 실시간. 주문창에 매수 가능 수량/매도 가능 수량 표시, 초과 입력 시 미리 경고(서버 거부 `InsufficientCash`/`InsufficientShares`도 안내).
5. **내 주문·내 체결**: 로컬 목록 대신 `GET /api/account/orders`·`trades` + 실시간 갱신. 상태 배지, 미체결만 취소 버튼. 기존 설명 패널 유지.
6. **랭킹 화면**: 상단 탭 "랭킹". 현재 라운드 상위 50(순위, 닉네임, 수익률, 평가액), 내 순위 강조, 갱신 시각, 지난 라운드 선택.
7. **라운드 안내**: "매일 05:00 새 라운드, 시작 자산 현금 1,000만 원 + 1,000주"를 주문창·랭킹에 짧게. 초기화(`marketReset`) 시 계좌·주문 다시 조회.
8. **개인정보 안내**: 푸터 링크 → 간단한 안내 화면(수집 항목: 이메일·닉네임·비밀번호 해시·로그인 기록, 목적, 보관, 탈퇴 방법). 교육용 모의투자이며 실제 돈·주식이 아니라는 고지.
9. **모바일 최소 대응**: 폭 390px에서 로그인·주문·계좌·랭킹이 깨지지 않게(호가창·차트는 세로 배치).

## 테스트
- 가입·로그인 폼 검증과 오류 표시, CSRF 재시도, 비로그인 주문창, 관리자 패널 노출 조건
- 계좌 패널 숫자 포맷(원·%·bp 변환), `accountUpdate` 반영, 매수 가능 수량 계산
- 내 주문 목록 상태별 취소 버튼, 랭킹 표시·내 순위 강조·지난 라운드 전환
- 목 모드 전체 흐름(가입 → 주문 → 계좌 변화)
